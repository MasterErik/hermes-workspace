Privacy Policy

hermes-workspace — last updated 2026-11-07

Who this covers

hermes-workspace is a personal, single-user OAuth 2.0 client. It is operated by and for one person on that person's own computer. There are no other users.

What data is accessed

With the account owner's explicit consent, the client may access the following data in that owner's own Google account:

  • Gmail messages and labels (read, send, modify)
  • Google Calendar events (read, create, delete)
  • Google Drive files (read, upload, download, share, delete)
  • Google Contacts (read only)
  • Google Sheets spreadsheets (read and write)
  • Google Docs documents (read and write)

Access happens only when the owner issues a command in their terminal. The client does not run in the background, does not poll, and does not collect data on its own schedule.

Where data is stored

  • OAuth credentials and refresh tokens are stored as a JSON file on the owner's own machine, in the Hermes Agent configuration directory (google_token.json).
  • Google API responses are held in memory to answer the current request only. They are not written to a remote server, a database, or any third-party service.

Sharing

No data is sold, rented, shared, transferred, or disclosed to any third party. No data is used for advertising. No data is used to train machine-learning models. The only network endpoints contacted are Google's own API endpoints (*.googleapis.com) and the language-model provider that the owner has configured themselves.

Google API Services User Data Policy

This client's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used solely to provide and improve the user-facing features the owner requests, and is never transferred to others.

Retention and deletion

The owner can delete all stored credentials at any time by running setup.py --revoke, which revokes the token at Google and removes the local file. Deleting that file removes every trace of stored access. Because no copy of the data exists anywhere else, revocation is immediate and complete.
