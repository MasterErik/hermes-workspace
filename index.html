hermes-workspace

A private OAuth client for the Google Workspace APIs.

hermes-workspace is a personal OAuth 2.0 client used by a single user to let their self-hosted Hermes Agent instance read and write their own Google account data.

The client runs locally on the owner's own machine as a command-line tool. It is not a public service, it has no sign-up, and it does not accept users or data from anyone else. All API calls are made directly from the owner's computer to the Google APIs using the owner's own credentials.

How the data is used

Access is limited to the Google account of the person who authorizes it. The client uses the Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs and People APIs only to perform the tasks that account owner explicitly asks for, for example searching their own mail, reading their own calendar agenda, uploading a file they selected to their own Drive, or reading a spreadsheet they pointed at.

OAuth tokens are stored locally on the owner's machine in the Hermes Agent configuration directory. Nothing is uploaded to any server operated by this project, because this project does not operate any server.
